## 🧩 About

**Lineage 2 Hack Menu** is a curated list of Lineage 2 open-source tools:

- **Overlays** — on-screen helpers, layout notes, radar, map tracker
- **Quality-of-Life Helpers** — config manager, loot tracker, HUD notes

Based on publicly available community tools and overlay helpers.

## ✨ Features

### ESP
- Radar Overlay — visualize nearby entities and points of interest
- Map Tracker — track positions and routes for study
- Loot Helper — highlight item drops and containers
- HUD Customization — adjust overlay elements for clarity

### Wallhack
- Item Catalog — browse items, stats, and descriptions
- Skin Notes — organize character appearances
- UI Themes — customize overlay colors and layout

### Aimbot
- Config Profiles — save and load overlay settings
- Hotkey Manager — assign keys for overlay toggles
- Safe Mode — conservative defaults for stability
